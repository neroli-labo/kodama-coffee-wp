# KODAMA COFFEE — WordPress版デモサイト

鳥取県大山の麓に佇む架空のカフェ「KODAMA COFFEE（木霊珈琲）」のWebサイトです。
1ページのLPとして制作したサイトを、WordPressオリジナルテーマとして7ページ構成にフル拡張しました。

**デモサイト**: https://neroli-labo.github.io/kodama-coffee-wp/

※ このリポジトリはWordPressで構築したサイトを静的書き出し（Simply Static）したデモです。お問い合わせフォームの送信は動作しません。

## ページ構成

- TOP — 木漏れ日の粒子アニメーション・パララックスヒーロー
- CONCEPT — コンセプト・三つの約束
- MENU — コーヒー / フード / スイーツ / 季節メニュー
- INTERIOR — 席のご案内・店内フォトギャラリー
- STORY — 店主の想い・お店のあゆみ（年表）
- NEWS — お知らせ（WordPress投稿で運用）
- CONTACT — お問い合わせ（Contact Form 7）

## 使用技術

- WordPress オリジナルテーマ（自作・テンプレート13ファイル）
- Sass（foundation / layout / component / page の分割設計）→ style.css へコンパイル
- Vanilla JavaScript（Intersection Observer・パーティクル演出・パララックス）
- Contact Form 7
- 画像: ChatGPT images 2.0 で生成（プロンプト設計も自作）
